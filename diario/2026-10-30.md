## Objetivo da sessão

Esta sessão teve como objetivo iniciar o projeto de homelab, montar o repositório e preparar a primeira VM.

## O que fiz

- Ao iniciar o projeto, defini como estação de trabalho o WSL com a distro Ubuntu 24.04, e como já tinha instalado o Oracle VirtualBox,
optei por ele para rodar as VMs.
- Ao criar as placas de rede, optei por utilizar NAT na WAN para isolar o lab da rede de casa.
- Para que o "atacante" fique dentro da rede do lab, irei utilizar o Kali como VM, e não no WSL.

## Problemas e resolução
Sempre ao me deparar com um problema, tentei entender as causas e como resolver. Alguns dos problemas encontrados nessa sessão foram:
- Arquivo Zone.Identifier na pasta do projeto: é uma sinalização de que o arquivo foi baixado da web, ou seja, é um metadado. Ele geralmente fica oculto no Windows, porém, ao copiar para o WSL, como o sistema de arquivos do Linux não tem ADS, ele acabou se tornando um arquivo visível. Como é inofensivo, foi removido da estrutura.
- Push falhou por problemas na autenticação: desde 2021, o GitHub não aceita senha da conta em operações Git. Para conseguir acesso ao repositório remoto, gerei uma chave SSH ed25519 com passphrase e troquei o remote de HTTPS para SSH.
- VirtualBox oferece apenas 4 placas de rede pela GUI: como a VM suporta até 8 placas pela linha de comando, adicionei a 5ª placa via VBoxManage.

## Aprendizados
Ao fazer a autenticação no GitHub, pude entender e praticar o uso de criptografia assimétrica, onde gerei uma chave privada que fica apenas no meu computador, enquanto compartilhei a chave pública com o GitHub para que a comunicação pudesse acontecer. Também verifiquei a fingerprint do servidor, para me certificar contra um man-in-the-middle.
Ao baixar a iso do OPNsense diretamente do site oficial, pude verificar o checksum disponível no site para comparar e garantir que o arquivo não sofreu alterações no download.
